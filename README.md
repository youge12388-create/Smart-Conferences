# 会议排班台 MeetingBoard

多人会议排班、统计与提醒工具。零依赖、轻量、中英双语，适合跨国销售/中介团队使用。

English summary: A lightweight multi-user meeting scheduler with per-person statistics, reminders and CSV export. Zero npm dependencies, bilingual (中文 / English).

## 功能 Features

- 账号密码登录：用户名 = 成员姓名（中英文名均可），密码 scrypt 加盐哈希存储；未登录只能看到登录页
- 企业微信免密登录：绑定企微 ID 的成员，在企业微信内打开应用直接登录，与账号密码指向同一账户
- 服务端会话：登录后签发 httpOnly cookie（30 天），所有操作以会话为准，停用成员立即无法登录
- 权限管理：普通成员可管理会议；添加/删除成员、全局设置、数据导入、重置密码仅管理员
- 日历排班：月视图直观排期，点日期快捷新建，支持每周重复会议
- 会议结构化录入：国家/市场、会议类型下拉选择（可自动学习新值），参会员工多选
- 时间冲突检测：同一员工同时段有会时自动提示
- 按员工数据指标：总场次、总时长、覆盖市场、按市场/类型分布、近12周趋势、员工排行
- 开会提醒：提前 N 分钟浏览器通知 + 声音 + 应用内铃铛；企业微信会前准备卡片可直达会议链接，到点对未确认参会者二次提醒
- 会议状态流转：计划中 / 已召开 / 已取消，一键标记，取消后不再提醒
- 周例会单场取消：某周不开可直接"取消本场"，统计自动剔除
- 出席确认（RSVP）：参会人在详情页确认参加/无法参加，谁确认了一眼可见
- 变更通知：会议被改期、取消、删除时，自动推送参会人（企微/邮件/在线提醒）
- 团队时区：会议时间按团队时区记录，成员按各自本地时区显示换算后的时间
- 成员不可用日期：录入休息日，排期时自动提示冲突
- 导出：会议列表导出 CSV（Excel 可直接打开），全量数据备份 JSON 导出/导入恢复
- 自动备份：数据写入时每小时自动滚动备份至 `data/backups/`（保留最近 20 份）
- 中英双语：右上角一键切换，外国员工可切英文界面
- 多员工：团队共享一份数据，实时同步（任何人修改，其他在线成员立即刷新）

## 快速开始 Quick Start

### Windows

双击 `start.bat`。若本机未安装 Node.js，脚本会自动下载便携版运行时（仅首次，约 40MB）。

### macOS / Linux

```bash
./start.sh
```

需要已安装 Node.js（>= 18，推荐 LTS）：https://nodejs.org

### 使用

1. 启动后浏览器打开 `http://localhost:3000`
2. 同一局域网的同事访问 `http://本机IP:3000`（启动窗口会打印局域网地址，如 `http://192.168.1.5:3000`）
3. 首次登录：用户名填"管理员"，密码为默认密码 `mb@123456`（可在 `config.json` 的 `auth.defaultPassword` 修改），登录后建议立即在「个人资料」中修改密码
4. 到「成员管理」添加其他成员（姓名即登录用户名），新成员的初始密码同为默认密码
5. 成员用「姓名（或英文名）+ 密码」登录；绑定企业微信ID的成员也可在企业微信内直接打开免密登录

> 注意：如需局域网其他电脑访问，请确保 Windows 防火墙放行 3000 端口（首次启动时按提示允许即可）。

## 外国员工远程访问 Remote access for overseas staff

局域网部署默认只有同一内网可访问。海外同事（如巴基斯坦、尼日利亚）远程使用时，任选其一：

1. **Tailscale（推荐，免费）**：在服务器电脑与海外同事电脑各安装 [Tailscale](https://tailscale.com)，登录同一账号后组网，海外同事用 Tailscale 分配的虚拟 IP + 3000 端口访问，无需公网 IP、无需开放端口。
2. **云服务器公网部署**：把整个文件夹放到有公网 IP 的云主机（海外访问建议香港/新加坡节点），安装 Node.js 后运行 `node server.js`，国内外均可直接访问。
3. **公司 VPN**：海外同事连公司 VPN 后访问内网地址。

代码无需任何修改，换部署位置只是访问地址不同；数据文件可随文件夹整体迁移。

## 数据 Data

- 所有数据保存在 `data/data.json`，纯文本 JSON，可随时复制备份
- 侧边栏「数据备份」可一键导出/导入全量备份
- 换机器部署：复制整个文件夹即可（或只复制 `data/data.json`）

## 配置与端口 Config

- 端口：默认 3000，可用环境变量覆盖：`set PORT=8080` 后运行，或 `PORT=8080 node server.js`
- 提醒时间：铃铛 → 齿轮 → 设置提前提醒分钟数（全局生效）

## 技术说明 Tech Notes

- 零 npm 依赖，仅用 Node.js 内置模块（http / fs / zlib）
- 内存占用约 30-40MB，空闲 CPU 接近 0，低配服务器或普通电脑均可运行
- 前端无框架、无 CDN，静态资源内置 gzip 压缩
- 数据写入采用防抖 + 原子替换，多人同时操作安全

## 企业微信接入（自建应用）

支持：企业微信 OAuth 免密登录 + 应用消息开会提醒 + 邮件提醒（成员录入邮箱后）。

### 1. 企业微信后台准备（一次性）

1. 管理后台 → 应用管理 → 自建 → 创建应用，记录 **CorpID / AgentId / Secret**
2. 应用详情 → 「开发者接口」：
   - **网页授权及JS-SDK**：填写已备案的可信域名（如 `mb.example.com`，必须 HTTPS、不带端口）
   - **服务器IP白名单**：填写部署服务器的公网 IP（否则调用 API 会报 403/权限错误）
3. 应用可见范围设为全体员工

### 2. 配置文件

复制 `config.example.json` 为 `config.json` 并填写：

```json
{
  "auth": {
    "defaultPassword": "mb@123456"
  },
  "wecom": {
    "corpId": "wwXXXXXXXXXXXXXXXX",
    "agentId": "1000002",
    "secret": "应用Secret",
    "publicBase": "https://mb.example.com"
  },
  "mail": {
    "host": "smtp.example.com",
    "port": 465,
    "secure": true,
    "user": "sender@example.com",
    "pass": "smtp密码",
    "from": "sender@example.com"
  }
}
```

不创建 `config.json`（或留空）时，企微与邮件功能自动关闭，工具以本地模式运行，不影响其他功能。

### 3. 员工绑定

管理员在「成员管理」中为每个员工录入：
- **企业微信ID**：企业微信通讯录里的 userid（用于免密登录和应用消息）
- **邮箱**：用于邮件提醒

### 4. 会议链接与提醒

- 新建或编辑会议时可填写“会议链接”（仅 HTTP/HTTPS），用于 Zoom、腾讯会议、Teams 或企业微信会议。
- “会议渠道”仅用于描述渠道；企业微信会前准备卡片优先打开“会议链接”，未填写时回到 MeetingBoard。
- 提前提醒分钟数由管理员在铃铛 → 设置中配置；设置为 15 时会收到会前准备温馨提醒。

### 5. 运行监控与机器人告警

在服务器的未提交 `config.json` 中填写 `alerts.wecomRobotWebhook` 和 `alerts.healthCheckUrl`。机器人地址含 key，不能写入源码、示例配置或日志。

建议在宝塔“计划任务”中每分钟执行一次：

```bash
cd /opt/Smart-Conferences && node scripts/health-monitor.js
```

该任务访问 `/healthz`；Node 项目停机时会通知机器人，恢复后再发送一次恢复消息。整台服务器或网络不可用时，需要外部监控服务。

### 6. 登录与提醒

- 员工在企业微信内打开应用（工作台入口/应用消息链接）→ 点「企业微信登录」→ 静默授权自动登录
- 会议开始前 N 分钟：参会员工的企业微信收到应用消息提醒，同时可发送邮件
- 未绑定企微的员工不受影响，可继续用「姓名 + 密码」登录（与企微登录指向同一账户）

### 5. 安全注意

- `config.json` 含应用密钥，切勿提交到代码仓库或分享；`auth.defaultPassword` 为所有成员初始密码，上线后请尽快修改
- 部署方式建议：内网直连（局域网）或 Tailscale / 云服务器公网（供海外员工），OAuth 登录要求 `publicBase` 能被企微服务器访问

## 限制与说明 Limitations

- 登录：账号密码登录（用户名=姓名，初始密码见 `config.json` 的 `auth.defaultPassword`，管理员可在「成员管理」重置他人密码）；绑定企微的成员可用企微免密登录；停用成员无法登录
- 会话保存在服务端内存，服务重启后所有成员需重新登录
- 时区：会议时间按团队时区（默认北京时间，管理员可在提醒设置中修改）记录；界面按每位成员的本地时区换算显示
- 统计口径：统计截至今天的实际应开场次，已取消的场次不计入；每周重复按范围内实际发生场次统计
- 提醒依赖浏览器通知权限：请允许通知，并保持页面打开（后台标签页即可）；离线时可通过企业微信/邮件收到提醒

## 目录结构 Structure

```
meetingboard/
├── server.js            # 服务端（零依赖 HTTP + JSON 存储 + SSE 提醒）
├── lib/
│   ├── dates.js         # 共享日期/周重复逻辑（服务端与浏览器共用，含单场取消）
│   ├── meeting.js       # 会议输入校验 / 变更判定 / 数据规整（v1→v2 迁移）
│   ├── auth.js          # 密码哈希（scrypt）/ 会话签发与校验
│   ├── wecom.js         # 企业微信接入（OAuth / token / 应用消息）
│   └── mail.js          # 邮件提醒（零依赖 SMTP）
├── test/                # 内置测试（node --test）
│   ├── dates.test.js
│   ├── meeting.test.js
│   └── auth.test.js
├── config.example.json  # 企微/邮件配置模板（复制为 config.json 使用）
├── start.bat            # Windows 一键启动
├── start.sh             # macOS/Linux 启动
├── public/              # 前端页面
│   ├── index.html
│   ├── app.js
│   ├── styles.css
│   ├── i18n.js          # 中英文字典
│   └── favicon.svg
└── data/
    ├── data.json        # 数据文件（自动生成）
    └── backups/         # 自动滚动备份（自动生成，保留最近 20 份）
```
